# Changelog 2.11.1

## Fixes

- **The new blocks printed `{f:translate(key: '…')}` at the reader instead of words.** The
  labels the answer card, the grid and the funnel speak were a literal json object in the
  template with an inline `f:translate` in each value. Fluid reads the outer brace of such an
  object as one expression of its own, cannot resolve it, and leaves the whole thing - the
  inline view helpers included - on the page. The strings are now translated in the controller
  and the template carries one variable, the way the chart and the screen data already did.
