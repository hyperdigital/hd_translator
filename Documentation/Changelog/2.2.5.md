# Changelog 2.2.5

## Fixes
- The backend module controller and `DatabaseEntriesService` had been copied over from the 3.x
  line while backporting fixes, which made them reference services that only exist there
  (`TranslationFormatService`, `TranslationCoverageService`, `TranslationQaService`). Building the
  dependency injection container failed with *Cannot autowire service ... but this class was not
  found*, so the extension could not be installed. Both are the 13 versions again, with the same
  fixes applied. This never reached a published release on this branch.

## New Features
- A screen that answers which languages people actually ask for: unique visitors per language for
  today, seven days, thirty days and in total, whether that is more or less than the thirty days
  before, how much of the language is already translated, and whether it exists as a real language
  of a site. Every column sorts, in the browser.

  It stays a patch release because 2.3.x belongs to the other branch of this same TYPO3 13 line.

## Changes
- The request and string counters are gone from the statistics, nobody needed them. A row is now
  its own primary key, 137 bytes against the 359 a row with counters took, so five thousand
  visitors a day cost 238 MB a year rather than 625.
- Old rows are dropped once a day instead of only when somebody opens a screen, which on an
  installation where nobody did meant never.
