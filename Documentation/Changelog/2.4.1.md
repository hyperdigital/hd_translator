# Changelog 2.4.1

## Fixes
- 2.4.0 could not be installed on TYPO3 13 at all: the backend module controller referenced
  `TranslationFormatService`, `TranslationCoverageService` and `TranslationQaService`, which only
  exist on the 3.x line, so building the dependency injection container failed with
  *Cannot autowire service ... but this class was not found*. The controller and
  `DatabaseEntriesService` were copied over from the 3.x branch while backporting fixes instead of
  having those fixes applied to the 13 versions of them. They are the 13 versions again, with the
  same fixes applied: the per run export directories, the guards against false where a string is
  required, the paged and searchable translation lists, and a single exported record served as a
  file rather than an archive.

  The multi format export (XLIFF 2.0, PO, JSON, YAML, CSV), the quality check on import and the
  coverage screen stay what they always were on this line: features of 3.x, not of 2.x. Exports
  here are XLIFF 1.2.
