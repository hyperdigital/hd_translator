# Changelog 2.2.4

## New Features
- The AI translation overview counts how many people asked for each language, not only how many
  strings it holds. The number of translated strings says how much text a language has; it does
  not say whether anybody wanted it. DeepL counts requests, and analytics cannot tell a visitor
  who used the translation from one who did not. The overview now shows unique visitors per
  language for today, 7 days, 30 days and in total, next to the number of requests, which is what
  decides whether a language is worth maintaining as real pages.

  Counting is on by default and needs no change in a project that already uses the frontend
  translation; it happens in the endpoint the frontend calls.

## Privacy
- What is stored is one row per language, per day, per visitor, where the visitor is an HMAC of
  the address and the user agent keyed with the installation's encryption key **and the day**. The
  same person therefore hashes differently tomorrow, and yesterday's rows can no longer be tied to
  anybody. No address and no user agent is written anywhere.
- Rows are dropped after a year, configurable, and the overview prunes them when it is opened.
- The whole counter can be switched off in the extension configuration.
