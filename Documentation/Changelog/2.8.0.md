# Changelog 2.8.0

## New Features
- **The demand chart answers three questions instead of one.** `Lines` is what it drew before,
  `Total` stacks the languages so the screen can say whether the demand is growing at all - the
  question behind "is this worth maintaining", which the lines never answered - and `Share` puts
  the same stack to a hundred percent, so the division can be read whatever the traffic did.
- **A seven day average.** Over ninety days and more the daily noise is louder than the trend the
  reader came for. One click, and the raw series is one click back.
- **Dragging across the plot zooms into that range**, with a `Reset zoom` beside the range
  buttons. The range still reloads the screen, because it decides the query; everything else is
  immediate.
- **The readout marks what it reads.** Every series gets a dot where the crosshair stands, and the
  tooltip carries the total of the day - the one number the lines cannot show.
- **Pointing at a language lifts it.** From the legend or from a table row: its line thickens and
  gains a fill, the others fade. Six lines that cross could not be followed any other way. The
  busiest day of the window is named in the plot.
- **The monthly history is finally drawn.** `getMonthlyHistory()` had been computed and handed to
  the screen since 2.6.0 and no template ever used it - one query per visit that nobody saw. It is
  now a stacked bar per month, hover or focus for the languages in it.
- **A sparkline per language in the table**, over the selected range. 41 visitors after one spike
  reads nothing like 41 steady, and the number alone cannot tell the two apart.
- **`Copy the table as CSV`** takes the table as it is read - current sorting included, sparklines
  left out. The numbers end up in somebody's slide deck either way.
- **The banner numbers are a funnel**: shown, the visitors behind that, the ones who agreed. Three
  bars next to each other say where the audience falls away; three tiles never did.

## Accessibility
- The chart takes focus and reads out with the keyboard: arrow keys move the readout, `Home` and
  `End` jump to the ends, `Esc` clears it. Its description points at the table below it, which
  holds every value the chart draws.
- The weekday profile carries its numbers above the bars. They used to live in a `title`
  attribute, which a touch screen never shows and a keyboard never reaches.
- The monthly history is focusable per month, so its breakdown is reachable without a pointer.

## Fixes
- `.hd-translator-muted` was used by the templates since 2.6.0 without ever being defined: the page
  descriptions and the "no rate" dash were plain body text.
- The reset button of the zoom is hidden with the `hidden` attribute, which Bootstrap's `.btn`
  display would have overridden - the button would have been there before anything was zoomed.
- Dragging across the plot used to start a text selection of the axis labels, which swallowed the
  release and left the selection rectangle standing. The chart now takes the drag, and a release
  anywhere on the page ends it.

## Changes
- Still no charting library. The backend ships plain scripts with no build step and its CSP does
  not admit a chart bundle from a CDN; the whole file is smaller than the loader of one would be.
- The ground a bar is drawn on is a token (`--hdt-track`) in both themes rather than
  `light-dark()`: the backend does not always set `color-scheme`, and a wrong ground is invisible
  until somebody looks.
- The strings the chart builds at runtime travel as `data-label-*` attributes, because a script
  cannot reach the label files.

## Upgrade
- No database change. Clear the frontend and backend caches so the new asset is served.
