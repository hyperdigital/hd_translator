# Changelog 3.7.1

## Fixes
- **`Real pages` claimed a language was already built when only its site configuration said so.**
  A language can sit in `config.yaml` with not one page translated into it - its urls answer 404
  and it is in no language menu - and the column still said "yes". That is the screen's own
  question answered backwards: it reports "already there" about the very languages somebody is
  deciding whether to build.

  The column now asks the page tree: a language counts when the site's root page has a
  translation in it that is neither deleted nor hidden. On the installation this was found on,
  two languages flipped to "not yet" - and they carry 1.27 million and 438 thousand translated
  characters between them, which makes them the strongest candidates to build rather than
  settled business.

- The same answer feeds the sentence under `Where the asking comes from` that counts how many
  people asked for a language that exists as real pages, so that number was wrong in the same
  way and is now right.
