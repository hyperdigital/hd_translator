# Changelog 3.2.1

## Fixes
- `initializeAction()` called `$this->redirect('syncLocallangs')` when the generated locallang
  configuration was not in the storage path. That redirect has never fired on TYPO3 12 and up:
  `redirect()` returns a response rather than throwing, and `processRequest()` discards whatever
  `initializeAction()` returns. The requested action then ran without the synchronized entries.

  The call is removed rather than repaired. An automatic jump into a synchronization that scans
  every installed extension is a heavy side effect of merely opening a screen, and that
  synchronization needs EXT:extensionmanager, which the redirect cannot know about without
  duplicating the check. The index already carries the button. Reported in
  [#32](https://github.com/hyperdigital/hd_translator/issues/32).

- An empty category list had one callout for two different causes, and the advice for one is the
  wrong advice for the other: it showed the `ext_localconf.php` example even when the only thing
  missing was the generated file. The two are told apart now.
