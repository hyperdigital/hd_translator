# Changelog 2.5.2

Found by walking every screen of the module on a real TYPO3 13.4.37 rather than by reading it.

## Fixes
- **Importing an XLF replaced the whole translation file.** `saveAction()` writes the file from
  whatever it is handed, and the import handed it only the units of the uploaded file. Sending an
  export to a translator and importing back the strings they worked on therefore erased every
  other one - 702 German labels down to 1 - with no backup, because the backup slot is only
  written by the delete. The imported units are laid over what is stored now, so keys the import
  does not mention keep their translation.

  Writing the file is one method shared with the save screen, and the import calls it directly:
  handing a whole file's worth of data to the save action through redirect arguments produces a
  `Location` header the web server refuses with 502.

- **Page content export and database entries export were fatal.** The flexform reader called
  `convertFlexFormContentToArray()` on `FlexFormTools`, where TYPO3 13 does not have it - there it
  lives on `FlexFormService`. Any record carrying a flexform field killed the export, which on a
  normal site is the first one. The service now asks whichever class owns the method;
  `FlexFormTools` stays for `getDataStructureIdentifier()`.

- **Exporting a single record was fatal**, and so was **importing into the database**. The
  controller read `DatabaseEntriesService::$rowType`, `::$rowTypeCouldBe` and `::$importStats`
  statically, but all three are protected instance properties. The import was the worse of the
  two: it wrote its rows and then died before rendering the result. Public getters for all three
  already existed.

- The exchange directory an export creates was removed on each return path but not in a
  `finally`, so an exception left it behind, as did the path where the archive turns out empty
  and the plain file is served.

## Changes
- The list of distinct source texts shows how many languages each one has. The query had been
  grouping and counting them all along; only the column was missing.
