# Changelog 2.3.2

## Fixes
- DeepL authentication. DeepL removed the legacy `auth_key` parameter in November 2025 and
  answers requests carrying it with 403, so every translation that was not already cached failed
  and the frontend kept showing the untranslated text. The key is sent as
  `Authorization: DeepL-Auth-Key` now. A body still built the old way has the parameter stripped
  rather than sent, so callers outside the extension keep working.
- The error of a failed DeepL call now carries DeepL's own response body.

## Performance
- The cached strings of a request are resolved with one query instead of one per string.
- Index on `tx_hdtranslator_ai_translation (target_language, original_source)`. Run the database
  analyzer after updating.
